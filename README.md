# CityFest Guide - приложение для поиска городских мероприятий

Пет-проект системного аналитика: полный цикл проектирования
приложения от Vision & Scope до OpenAPI-спецификации.

> **Статус:** пет-проект. Имеются аналитические артефакты, а также прототип в Figma, использующийся для демонстрации и содержащий некоторые базовые функции

---

## О проекте

**Проблема:** в городе нет удобного приложения, где можно
найти событие на выходные и сразу купить билет. Существующие
решения не имеют фильтров при поиске и в целом обладают неудобным интерфейсом.

**Решение:** мобильное приложение с персонализированной лентой,
верификацией организаторов и быстрой покупкой билетов.

**Роль:** системный аналитик - проектирование с нуля.

## Как посмотреть проект

1. **Начните с** [Vision & Scope](Vision and Scope документ.docx)
2. **Затем** [User Stories](User Story.docx)
3. **Диаграммы** - в папках 'BPMN', 'ERD' и в файле 'Use Case.png' 
4. **API** - откройте 'openapi.yaml' в [Swagger Editor](https://editor.swagger.io)
5. **SQL** - файлы в папке 'SQL', можно запустить в PostgreSQL
6. **Опробовать прототип** - можно открыть по ссылке https://www.figma.com/design/lkPBIejoHNUd12z3rZFdMZ/CityFest-Guide?node-id=16-84&t=DjxqhEmaX6Fg20MK-1 которая также хранится в файле 'Ссылка на прототип Figma.txt'

## Что я узнал в процессе

- Как проектировать процесс модерации, сочетая автоматическую проверку + ручную только для серой зоны

- Как описывать API в OpenAPI так, чтобы из него генерировалась документация
